# Raw Sources

外部仕様、記事、調査結果、議事録、ユーザーから提供された設計資料などを、受領時の内容のまま保存する場所です。
この README 自体はディレクトリの運用説明であり、取り込み対象の raw source ではありません。

## 規則

- ファイル名は原則として `YYYY-MM-DD-短い名前.拡張子` とします。
- 一度取り込んだ資料の本文は編集、整形、要約、削除しません。
- 訂正版や新版は新しいファイルとして追加します。
- 資料間の矛盾や置換関係は `../wiki/` に記録します。
- パスワード、Cookie、API トークン、OTP、個人情報を追加しません。
- ライセンス上リポジトリへ複製できない資料は保存せず、Wiki から公式 URL と参照日を示します。

プロジェクト自身のコードや設定は、ここへ複製せずリポジトリ内の元ファイルを一次情報として参照します。
